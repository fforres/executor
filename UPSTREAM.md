## Notes

`requiresApproval` for MCP tools is derived in one place, `toToolDef` in `packages/plugins/mcp/src/sdk/plugin.ts` (`destructiveHint === true`), from the same `tools/list` entry the stamp keeps, and `resolveAnnotations` reads that stamp. We found no race: a first refresh and a second one agree (`refresh.test.ts`). A tool reads `requiresApproval: false` only when its `tools/list` entry carries no `destructiveHint: true` at that moment (annotations missing or a failed listing decode), so check what the server advertised before suspecting the sync.
